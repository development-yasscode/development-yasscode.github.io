PRIVACY POLICY

日読。プライバシーポリシー

制定日：2026年7月10日　改定日：2026年9月21日

「日読。」（以下「本アプリ」）は、AMANE（個人事業。以下「開発者」）が開発・運営する、 読書を記録し、習慣として続けるための iOS アプリです。 本アプリは、あなたの読書の記録があなた自身のものであることを大切にしています。 読書データはすべてお使いの端末の中に保存され、開発者がその内容を閲覧することはできません。

1. アカウント登録について

本アプリの利用にアカウント登録は不要です。氏名・メールアドレス・電話番号などの 個人情報の入力を求めることはありません。

2. 端末内に保存される情報

次の情報は、すべてお使いの端末の中にのみ保存されます。

  • 登録した書籍の情報（書名・著者名・ISBN など）
  • 読書の記録（読書時間・読んだページ範囲）
  • メモ、および問いかけへの回答
  • 読書の実績（連続日数・朱印など）
  • サブスクリプションの購読状態の控え

これらの情報が開発者のサーバーへ送信されることはなく、開発者がアクセスすることも できません（第3条の AI 機能に同意して使った場合の書誌情報の送信を除きます。 メモ・回答が送信されることはいかなる場合もありません）。端末のバックアップ（iCloud バックアップ等、iOS の標準機能）には、 お客様の設定に応じて含まれる場合があります。

3. 外部に送信される情報

本アプリは、次の目的に限り、外部のサービスと通信します。

書誌情報の取得

書籍を登録する際、書名や著者名を取得するために、書籍の ISBN またはタイトル検索の 検索語を、書誌情報の提供元（openBD API、国立国会図書館サーチ、楽天ブックス書籍検索 API）に 送信します。利用者に関して送信されるのはこれらのみで（このほかに API の利用に必要な アプリ側の資格情報を付けます）、個人を特定できる情報は含まれません。 取得した書誌情報に表紙画像の URL が含まれる場合、その画像を提供元から取得して 端末内に保存します。

書架（青空文庫等の公開作品）のカタログ取得

「書架から選ぶ」で作品一覧を表示するために、開発者が運営する書架サービス「書架」から 公開カタログを取得します。この通信で本アプリが送信するのはカタログの取得要求だけで、 利用者の入力・読書記録・端末や利用者を識別する情報は付けません（通信に伴う通常の 接続情報は他の HTTPS 通信と同様です）。「書架で読む」を選ぶと、作品の本文は本アプリ内 ではなく Safari で書架サービスのページとして開きます。Safari での閲覧には Safari と お使いの端末の設定が適用されます。

匿名の利用統計（TelemetryDeck）

本アプリには匿名の利用統計を送信するための仕組み（TelemetryDeck 社の SDK）が 組み込まれていますが、現在のバージョンでは有効化しておらず、利用統計は送信されません。 将来のバージョンで有効化する場合は、本ポリシーを改定したうえでアプリ内でお知らせします。

AI 機能（Premium）

Premium にご加入の方が、アプリ内で同意のうえ AI 機能（問いかけの生成・次の一冊の選書）を 使ったときに限り、書名・著者名・ジャンル・読書の進み具合（現在のバージョンでは 読了状態のみ。選書では蔵書の一覧）を、開発者のサーバーを経由して OpenAI 社の API に 送信します。読了状態は選書時だけ送信します。 メモや問いかけへの回答の内容は送信しません。 送信された情報がモデルの学習に使われない API 区分を利用しています。 OpenAI 社では不正利用の監視のため最大30日間保持されることがあります。 開発者のサーバーに残る生成の記録は90日で削除されます。 この機能によるデータ送信は、設定画面からいつでも取り消せます。

また、AI 機能のご利用にあたり購読状態を確認するため、Apple が発行する署名済みの トランザクション情報を開発者のサーバーに送信します。署名済みトランザクション情報から 開発者が保存するのは、ハッシュ化された識別子と、AI 機能の利用回数および利用量 （処理したデータ量を示すトークン数）です。生成の記録（送信した書誌情報と生成結果）は 上記のとおり90日で削除されます。

4. 購入情報について

サブスクリプション（Premium）の購入・更新・解約は、すべて Apple の App Store を 通じて処理されます。開発者がクレジットカード番号などの決済情報を取得することは ありません。購読状態を確認するため、Apple が発行する匿名のトランザクション識別子を 端末内に保存します。

5. 広告について

本アプリは、第三者の広告配信 SDK を使用していません。無料版の画面に広告枠が 表示される場合も、外部への情報送信は行われません。

6. データの書き出しと削除

アプリ内のバックアップ機能により、読書データをファイルとして書き出すことが できます。本アプリを端末から削除すると、端末内のすべてのデータが削除されます。 開発者はデータの複製を保持していないため、削除されたデータを復元することは できません。

7. ポリシーの変更

本ポリシーの内容を変更する場合は、本ページにて告知し、改定日を更新します。 重要な変更を行う場合は、アプリ内でもお知らせします。

8. お問い合わせ

本ポリシーに関するお問い合わせは、 お問い合わせ窓口（GitHub Issues） までお願いいたします。

開発者の氏名・所在地は、法令に基づくお求めがあれば、お問い合わせ窓口を通じて 遅滞なくお答えします。
